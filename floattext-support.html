FloatPrompt 隐私政策

你的隐私是我们的首要原则

最后更新：2024 年 8 月

核心承诺

FloatPrompt 是一款本地优先的提词器应用。我们不收集、不存储、不上传您的任何个人数据。 所有核心功能完全在你的设备上运行，无需注册账户，无需联网。

✓ 我们不跟踪你

FloatPrompt 不包含任何广告、用户画像或行为追踪。没有第三方分析 SDK，没有设备指纹采集。

✓ 数据全在本地

你的稿件内容、设置偏好和录制视频均仅存储在你的设备上。我们无权访问，也无法访问。

系统权限使用说明

📷 相机

仅设备端 在录制模式中访问相机，用于拍摄你的口播视频。视频内容仅保存到你的设备相册和 App 本地目录，不会上传至任何服务器。

🎤 麦克风

仅设备端 仅在开启"语音跟随"功能时使用，用于实时识别你的朗读进度以便提词自动滚动。音频处理完全在本机进行，录音数据不会被保存或传输。你也可以选择不使用此功能——FloatPrompt 支持手动滚动模式。

🗣 语音识别

仅设备端 语音跟随功能依赖 Apple 的语音识别框架。识别过程在你的设备上完成，识别结果仅用于匹配浮动的提词文本，不会离开你的设备。Apple 可能根据其隐私政策处理语音数据以改进识别服务，详见 Apple 隐私政策。

🖼 相册

仅写入 FloatPrompt 使用"仅添加"权限，只在你主动保存录制视频时将成片写入相册。我们不会读取或扫描你的相册内容。

数据存储与技术细节

UserDefaults（系统偏好存储）

你的 App 偏好设置（如字体大小、滚动速度、显示模式等）通过苹果的 UserDefaults 机制存储在设备本地。这些数据仅在 App 内部使用，不包含任何个人身份信息。 已按 Apple 要求声明 NSPrivacyAccessedAPICategoryUserDefaults 的使用原因（CA92.1），表明仅用于存储用户偏好，不用于指纹识别。

Keychain（安全存储）

当你配置第三方 AI 服务时，你输入的 API 密钥会使用 iOS 系统级 Keychain 加密存储。密钥仅在发送 AI 请求时从 Keychain 读取，用完即弃，不缓存于内存。

Core Data（稿件存储）

你的提词稿件文本通过 Core Data 持久化存储在 App 的私有沙盒内。其他 App 无法访问这些数据。

AI 助手功能

涉及第三方 AI 稿件助手需要你自己配置 OpenAI 兼容的 API 服务地址和密钥。当你使用 AI 生成/改写稿件时：

  • 当前稿件文本会发送到你配置的第三方 AI 服务。
  • FloatPrompt 本身不收集、不中继、不记录这些请求。
  • 数据传输的安全性取决于你配置的 API 地址（建议使用 HTTPS）。
  • 请查看你所使用 AI 服务的隐私政策以了解其数据处理方式。

你可以随时清除 AI 配置，此后此项功能完全不会产生网络请求。

内购与 App Store

专业版订阅和终身买断通过 Apple App Store 处理。所有支付信息由 Apple 管理，FloatPrompt 无法接触你的付款详情、信用卡号或账单地址。交易记录仅存在于你的 Apple ID 账户中。

儿童隐私

FloatPrompt 不针对 13 岁以下儿童设计。我们不会故意收集儿童的个人信息。

政策变更

我们可能在更新 App 时修订本隐私政策。重大变更将在 App 内以弹窗通知。建议定期查看本页面以了解最新版本。
