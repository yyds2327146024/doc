关于 FloatPrompt

FloatPrompt 是一款为口播创作者设计的提词器 App。通过画中画技术将稿件悬浮在屏幕最上层， 让你在拍摄视频、直播或开会时一边看稿一边自然表达。支持自动滚动、语音跟随、逐段翻页和 内建录像功能，是短视频创作者的得力工具。

核心功能

  • 📱 画中画悬浮：稿件浮在任何 App 上方，纯净无播放按钮
  • 📝 自动滚动：可调速、循环播放，解放双手
  • 🗣 语音跟随：说话到哪，稿子滚到哪（本机离线处理）
  • 📄 逐段翻页：适合演讲、录课等节奏精确的场景
  • 🎥 内建录像：直接录制口播视频，提词文字不录进画面
  • 🤖 AI 稿件助手：接入你自己的 AI 服务，生成和润色口播稿

快速入门

1
创建稿件

点击首页的「+」按钮，输入你的口播文字内容。支持从剪贴板粘贴。

2
打开画中画权限

首次使用前，确保 iPhone 「设置 → 通用 → 画中画」中「自动开启画中画」已打开。

3
开始悬浮

点击任意稿件，点击「开始悬浮」。按 Home 键返回桌面，提词会始终浮在最上层。

4
自定义样式

在设置中调整文字大小、颜色、滚动速度和背景透明度，让提词最适合你的阅读习惯。

常见问题

画中画窗口没有出现？

请检查：

  • 确保「设置 → 通用 → 画中画 → 自动开启画中画」已打开。
  • iOS 16.6 及以上系统才支持本功能。
  • 确认稿件内容不为空。
语音跟随不准确？

请尝试：

  • 在安静环境中使用，减少背景噪音。
  • 说话速度稍放慢，发音清晰。
  • 确保已授予麦克风和语音识别权限。
  • 语音识别完全在设备端完成，无需联网。
免费版有什么限制？

免费版提供以下额度，足够日常轻度使用：

  • 最多保存 3 篇稿件
  • 单次悬浮提词最长 60 秒
  • 单次录像最长 3 分钟
  • 逐段翻页和 AI 助手为专业版功能

升级专业版后解除所有限制。

如何配置 AI 助手？

设置 → AI 配置，填入你自己的 OpenAI 兼容 API 地址、模型名称和 API Key。配置保存在本地 Keychain，不会上传。

录制的视频在哪？

录制完成后点击「保存到相册」，视频会保存到你的系统相簿。也可以选择仅保存到 App 内，稍后再导出。

如何恢复购买？

进入付费墙页面（点击任意专业版功能入口），点击底部的「恢复购买」。你在其他设备上的订阅或买断将自动恢复。

如何取消订阅？

在 iPhone 上：「设置 → Apple ID → 订阅 → FloatPrompt → 取消订阅」。取消后当前周期内仍可继续使用，到期后不再自动续费。

支持哪些设备？

iPhone（iOS 16.6+）、iPad（iPadOS 16.6+）。iPad 支持横竖屏全方向使用。

系统要求

  • iPhone 或 iPad，运行 iOS / iPadOS 16.6 及以上
  • 画中画功能需设备支持（iPhone 7 及更新机型）
  • 录像功能需后置摄像头
  • 语音跟随需麦克风权限（可选功能）
